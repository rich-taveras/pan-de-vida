# Pan de Vida

Página oficial del micro bakery casero de Rich Taveras en Chantilly, VA: pan de masa madre 100% integral (500 g de harina integral + 380 g de agua, 76% de hidratación), fermentación natural, sin levadura comercial. Nombre por Juan 6:35 — «Yo soy el pan de vida».

**En vivo:** https://rich-taveras.github.io/pan-de-vida/

- Bilingüe ES/EN con pop-up de idioma (mismo patrón que Pizza Friday).
- Estado: fase de prueba — todavía no se vende; lista de espera abierta (el formulario confirma en pantalla, no guarda datos).
- Fuente oficial: este repositorio (GitHub). Si se edita, se edita el artefacto "pan-de-vida" en la app y se re-exporta/re-sube — no editar este repo a mano.
- Nota legal: los horneados caseros que no necesitan refrigeración se venden directo al consumidor en Virginia bajo la exención cottage food (§ 3.2-5130).
